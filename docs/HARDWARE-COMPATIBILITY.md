# Hardware compatibility model

- Detected: device/resource enumerated.
- Identified: vendor/model identifier resolved.
- Driver present: a driver is available in the build.
- Function tested: a documented test exercised the device.
- Verified: repeatable tests passed on a named profile.
- Unsupported: known incompatibility or absent driver.
- Unknown: insufficient evidence.

Detecting a Wi-Fi adapter does not prove Wi-Fi works. VM results apply to virtual hardware, not automatically to the physical host. Never invent test outcomes.
